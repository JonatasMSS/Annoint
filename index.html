O Anoint é seu espaço para anotar imagens com precisão. Comece pela imagem de exemplo ou importe as suas.

  1. Escolha uma classe na barra lateral.
  2. Ative Caixa e arraste sobre a imagem.
  3. Selecione uma caixa para ajustar a posição, o tamanho ou a classe.
  4. Marque a imagem como concluída, mesmo quando não houver objetos.
  5. Exporte o projeto em JSON para guardar uma cópia com as imagens.

As alterações são salvas neste dispositivo. Seus arquivos não são enviados a um servidor.

Nesta entrega, a anotação é manual. Agentes e integração MCP chegam em uma próxima etapa.

Exportar anotações

Uma caixa por imagem nesta classe. Exporta o centro em pixels e a visibilidade em Label.csv por pasta. Imagens sem essa classe recebem visibilidade 0; outras classes não entram no CSV. Status é 0, sem eventos.

YOLO inclui imagens, caixas normalizadas, classes.txt e data.yaml. GIF não é aceito neste formato. Treino e validação usam as mesmas imagens; separe os conjuntos antes de treinar.
